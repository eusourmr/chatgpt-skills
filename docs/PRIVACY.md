# CS Navigator Privacy

CS Navigator is a skill-only plugin. Its core workflow consists of instructions and a bundled catalog snapshot used inside the OpenAI product surface.

## Data flow

The core CS Navigator plugin does not operate a developer-controlled server, does not require an external account, does not introduce an MCP connection, and does not add network calls to a third-party service.

The developer does not receive the contents of your ChatGPT conversation through CS Navigator's core plugin architecture.

Your use of ChatGPT itself remains subject to OpenAI's applicable privacy terms, data controls, workspace policies, and product settings.

## External sources

CS Navigator may describe metadata about externally published skills contained in its bundled snapshot. That metadata is used for discovery and trust labeling; the core plugin does not contact those external repositories during a normal chat execution.

## Future changes

If a future release introduces an app, MCP server, external API, authentication, or additional data transfer, this policy must be updated before that release is published.
