# CS Navigator Support

CS Navigator is an independent community project.

## Get help

For installation, plugin behavior, bug reports, documentation problems, or feature requests:

- Open a GitHub issue: https://github.com/eusourmr/chatgpt-skills/issues
- Browse existing issues before opening a duplicate.
- Include the CS Navigator version and the exact error or review finding when possible.

## Security or privacy

Do not post passwords, API keys, private conversation content, health information, payment credentials, or other sensitive personal data in a public GitHub issue.

For privacy information, see:
https://github.com/eusourmr/chatgpt-skills/blob/main/docs/PRIVACY.md

## Scope

Support covers the CS Navigator project and its published plugin package. OpenAI account, billing, platform availability, and product-level incidents remain under OpenAI support.

CS Navigator is not affiliated with or endorsed by OpenAI.
