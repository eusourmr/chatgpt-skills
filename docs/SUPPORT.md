# CS Navigator Support

CS Navigator is maintained in the public repository:

https://github.com/eusourmr/chatgpt-skills

## Get help

For installation, plugin behavior, capability-registry questions, bug reports, or documentation corrections, open a GitHub issue:

https://github.com/eusourmr/chatgpt-skills/issues

Before opening a new issue, check existing issues and the current release notes.

## Security and privacy

Do not post passwords, authentication tokens, private keys, health information, financial account credentials, or other sensitive personal data in a public GitHub issue.

For security-sensitive reports, use the repository's private security-reporting mechanism when available rather than a public issue.

## Scope

Support covers CS Navigator packaging, routing behavior, capability metadata, registry evidence, and the public read-only MCP service.

CS Navigator does not provide emergency, healthcare, legal representation, investment management, or other regulated professional services.
