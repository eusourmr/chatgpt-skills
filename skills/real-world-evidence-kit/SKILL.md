# Real-World Evidence Kit

## Collect when relevant
Timeline, photos/video, receipts/invoices, contracts, protocols, emails/messages, names/roles, values, screenshots, serial/order/account references, prior requests and responses.

## Integrity rules
Preserve originals; note date/time/source; distinguish original from annotation; do not edit evidence in a way that changes meaning; do not fabricate missing records.

## Systemic contract
Prefer the smallest useful intervention, preserve user agency and explicit uncertainty, and leave a reusable artifact when that reduces future effort.
