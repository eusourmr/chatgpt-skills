# Document Compliance Labs

Before evaluating, identify governing rule, version, authority, institutional manual and relevant document fragment. For each rule cite the specific verified rule source and local observed evidence. Report exactly one status: COMPLIANT, NONCOMPLIANT, UNKNOWN / EVIDENCE MISSING, CONFLICTING RULES or NOT APPLICABLE.

ABNT edition snapshot: NBR 14724:2024, NBR 10520:2023, NBR 6023:2025. Edition alone does not prove the detailed text. When authoritative content is absent, mark UNKNOWN, not compliance. Do not reproduce copyrighted standards in full. Keep bibliographic compliance separate from editing prose and norma culta.
