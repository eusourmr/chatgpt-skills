# CS Navigator Labs Web 0.20.0-beta.8 — candidato privado

Esta pasta guarda apenas os arquivos diferenciais da beta.5. O construtor em `scripts/build-cs-web-labs-beta5.py` parte dos 13 arquivos da beta.4 e cria um ZIP independente e reproduzível.

O incremento é uma **competência transversal de engenharia contextual de prompts no curador**, sem acrescentar uma sétima Skill. O próprio ChatGPT interpreta o pedido: não existe modelo neural novo, execução automática do compilador PC-01 ou ferramenta adicional conectada.

A versão estável 0.17.0 e a beta.4 são **bases de regressão e evolução**, não produtos que nunca possam ser alterados. A beta.5 preserva os dois artefatos enquanto sua própria integração é qualificada. Ao demonstrar benefício, a melhoria poderá seguir para a linha principal com versionamento, rollback e atualização simplificada.

**Distribuição:** execução do workflow de GitHub Actions gera ZIP e SHA-256. Instalação ou sincronização dentro do ChatGPT depende das permissões e do suporte do host; nenhum commit por si só atualiza o plugin instalado. O app Registry mantém seu vínculo anterior. UMNOO/Noem permanece separado, sem ponte ou compartilhamento de dados.

Beta.6 fixes the specialist URI, diagnostic-first behavior, and mechanical routing reports. No seventh Skill.

## beta.7 — existing UX and text skills enriched
No new Skills are installed. # CS Navigator Labs Web beta.8 — conhecimentos de curadoria

Base: beta.7, preservando todas as seis Skills e o Registry previamente registrado. A beta.8 corrige uma frase defeituosa no curador, registra nove regras de conhecimento com proveniência e inclui referência humana para decisões sobre fronteiras entre UX, texto, design-system, depuração e modo nativo.

**O que se aprende:** quais métodos realmente são úteis, quando não usar uma Skill, como distinguir conhecimento revisado de aplicação observada e como sair de impasses sem criar etapas desnecessárias.

**O que não se afirma:** aprendizagem neural, criação de novo modelo, memória persistente, classificação automática determinística, execução da Skill apenas pelo JSON, ganhos quantitativos sem comparação, ponte UMNOO, auto-instalação do plugin ou seis Skill reads sem rastros reais.

Arquivos: `knowledge/curation-knowledge.json`, `references/CURATION_DECISIONS.md` dentro da Skill curadora. O arquivo `NOTICE-UX-SOURCES.md` da beta.7 permanece intacto. A `beta.8` é compilada de maneira reprodutível por `scripts/build-cs-web-labs-beta8.py`; o CI valida o contrato da fonte, os hashes e a integridade do ZIP. A versão do plugin pessoal é um estado separado do build GitHub.
