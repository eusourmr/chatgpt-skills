# UI Copy Integrity — semantic and factual QA

This profile supplements Text Integrity Labs only for interface microcopy; it does not transform all prose into a rigid product-UI voice.

## Source truth

Preserve the user's actual intention, terminology, numbers, consent, modality, negation, conditions and quotes. A feature or claim must come from a supplied source or a real verification; unverified statements are not approved copy. Avoid inventing testimonials, speed percentages, dates, ratings or sample customer metrics. When showing synthetic test data, identify it as **illustrative** and never blur it into factual product claims.

## Element-level review

| Element | Check | Failure to avoid |
| --- | --- | --- |
| Button/CTA | short but action-specific, aligned to the operation | "Continue" for a destructive action or ambiguous generic verb |
| Input | visible label, supported formats, help and error state | placeholder treated as the only label |
| Error | what happened, recoverable next step, retained input | blame, vague denial or unfounded success promise |
| Metric | value, unit, comparison period, exact source | unexplained +12%, ungrounded endorsement |
| Notification | state transition, timing, action when needed | success toast without confirmed save |
| Accessibility name | same intent as visible control, localized | button says "Edit" but screen reader announces "Delete" |
| Marketing copy | product-specific and evidence-backed | unverifiable superlatives or invented feature guarantees |

## Verification and meaning

An editing suggestion is not a product change. Compare original and revised labels against the UI's actual behavior and authorization. If shortening changes scope, condition, promise, audience or legal meaning, use the **mandatory advance warning** from the parent Text Integrity Skill before showing the revised material. When there is no material change, give the polished result without clutter.

Respect regional variation, idiomatic PT-BR, translations and intentional voice. Emojis, punctuation and bold language are not banned as universals; remove them only when they harm clarity, accessibility or the established brand.
