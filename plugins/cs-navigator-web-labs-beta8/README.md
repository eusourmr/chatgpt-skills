# CS Navigator Labs Web beta.8 — conhecimentos de curadoria

Base: beta.7, preservando todas as seis Skills e o Registry previamente registrado. A beta.8 corrige uma frase defeituosa no curador, registra nove regras de conhecimento com proveniência e inclui referência humana para decisões sobre fronteiras entre UX, texto, design-system, depuração e modo nativo.

**O que se aprende:** quais métodos realmente são úteis, quando não usar uma Skill, como distinguir conhecimento revisado de aplicação observada e como sair de impasses sem criar etapas desnecessárias.

**O que não se afirma:** aprendizagem neural, criação de novo modelo, memória persistente, classificação automática determinística, execução da Skill apenas pelo JSON, ganhos quantitativos sem comparação, ponte UMNOO, auto-instalação do plugin ou seis Skill reads sem rastros reais.

Arquivos: `knowledge/curation-knowledge.json`, `references/CURATION_DECISIONS.md` dentro da Skill curadora. O arquivo `NOTICE-UX-SOURCES.md` da beta.7 permanece intacto. A `beta.8` é compilada de maneira reprodutível por `scripts/build-cs-web-labs-beta8.py`; o CI valida o contrato da fonte, os hashes e a integridade do ZIP. A versão do plugin pessoal é um estado separado do build GitHub.
