# Overwhelm to Next Action

## Purpose
Convert operational overwhelm into a manageable sequence.

## Workflow
1. List the obligations that actually exist.
2. Identify urgent/deadline-sensitive items.
3. Choose one action that can be started now.
4. Limit today's list to a small number of meaningful items.
5. Move non-urgent items to later.
6. Mark waiting-on and blocked items.

## Boundaries
This is operational organization, not mental-health diagnosis or treatment. Do not frame distress as pathology.

## Output
Now / Today / Later / Waiting / Can drop.

## Systemic contract
Prefer the smallest useful intervention. Preserve user agency, explicit uncertainty, and reversible steps. Leave a reusable artifact or learned pattern when that reduces future effort.
