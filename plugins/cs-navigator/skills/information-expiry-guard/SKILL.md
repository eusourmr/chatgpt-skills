# Information Expiry Guard

## Record
Claim/information; source/authority when available; verified on; applies to; known expiry/review date; event requiring recheck; state current | stale | unknown.

## Boundary
Do not invent validity periods.

## Systemic contract
Prefer the smallest useful intervention, preserve user agency and explicit uncertainty, and leave a reusable artifact when that reduces future effort.
