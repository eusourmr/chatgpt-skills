# Life State Map

## States
resolved | active | blocked | waiting | next | dropped

## Each item
Task/decision, state, owner, dependency, evidence, and next transition condition.

## Boundary
A state map is a user-visible artifact, not hidden memory.

## Systemic contract
Prefer the smallest useful intervention, preserve user agency and explicit uncertainty, and leave a reusable artifact when that reduces future effort.
