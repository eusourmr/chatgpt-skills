# CS Navigator Labs Web 0.20.0-beta.5 — candidato privado

Esta pasta guarda apenas os arquivos diferenciais da beta.5. O construtor em `scripts/build-cs-web-labs-beta5.py` parte dos 13 arquivos da beta.4 e cria um ZIP independente e reproduzível.

O incremento é uma **competência transversal de engenharia contextual de prompts no curador**, sem acrescentar uma sétima Skill. O próprio ChatGPT interpreta o pedido: não existe modelo neural novo, execução automática do compilador PC-01 ou ferramenta adicional conectada.

A versão estável 0.17.0 e a beta.4 são **bases de regressão e evolução**, não produtos que nunca possam ser alterados. A beta.5 preserva os dois artefatos enquanto sua própria integração é qualificada. Ao demonstrar benefício, a melhoria poderá seguir para a linha principal com versionamento, rollback e atualização simplificada.

**Distribuição:** execução do workflow de GitHub Actions gera ZIP e SHA-256. Instalação ou sincronização dentro do ChatGPT depende das permissões e do suporte do host; nenhum commit por si só atualiza o plugin instalado. O app Registry mantém seu vínculo anterior. UMNOO/Noem permanece separado, sem ponte ou compartilhamento de dados.
